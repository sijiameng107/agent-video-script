# 需求

面向短视频创作者。必填 theme、audience、platform、target_seconds、style；合成素材含来源 ID、版本、事实、关键词和可用画面，另提供品牌禁用词及中性文案。输出可编辑标题、分镜画面/旁白、来源、逐镜预计时长和合计、风险及状态。

验收覆盖正常生成、缺关键信息、无素材、工具故障、超时长修改或明确失败。必须先有素材依据，当前版本的时长和规则两项检查通过才可 completed；不能捏造效率数据。时长是上限，不强行补齐。

最多 14 次决策/工具动作；达到上限返回 incomplete。无素材/永久故障/约束无法满足时可请求补充，保留已生成稿件及检查结果。
